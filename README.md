# Logistic management system
## Intro
Logistic staff can use a web application to manage the system architecture. A Driver should be able to understand how to effectively work with the system. A customer can receive notifications regarding their delivery.
- [ ] API using .NET Web API will be handled by the front-end application. 
## Project overview
A logistic platform that aims to use entities related to the industry to help make the system architecture more efficient. It will contain a driver and delivery entity. 
## Logistics Digital Solutions
The project will help a logistic company manage their system architecture requirements.
